02

浏览器网络

独立于 Cookie 同步的全 Chrome 代理设置

Agent 必须主动启用本机浏览器接入服务，并监听 127.0.0.1 上的对应端口。

Chrome 代理 API 不等于完整 VPN。DNS、WebRTC、QUIC / UDP 的泄漏边界仍需真实 Chrome 验证。
03

站点授权

从已打开标签页选择，避免手动输入网址

支持 HTTP 与 HTTPS。HTTP 网站的数据访问未加密，可能暴露 Cookie/Token；跨设备同步依然端到端加密，授权不会自动创建配对。
