组合路由规则

路由模式
默认兜底动作

匹配规则 · 从上到下执行

同一栏多个值任选其一，不同栏同时满足；逗号分隔，留空或 * 表示任意。进程可填名称或完整路径，目标可填域名、IPv4/IPv6 或 CIDR 网段。

进程名、域名和 IP 均支持前后通配：* 匹配任意长度，? 匹配单个字符。例如 chrome*、*example*、192.168.*、*.1、2001:db8:*。

启用 / 名称 进程 域名 / IP 目标端口 协议 动作 / 出口 操作

“UDP 必须使用原生数据报”仅影响 PROXY UDP；勾选后会拒绝 TLS 隧道和不支持数据报的旧出口，不回退到可靠流传输。

透明代理排除进程

本程序及中继连接自动直连。点击“保存并应用规则”同时保存此列表。

透明代理通过捕获的 DNS 应答关联域名；加密 DNS、缓存命中和共享 IP 可能只能识别 IP。没有可靠关联时，域名条件不会命中。SOCKS5/HTTP 使用应用请求的域名；本机进程可识别时参与进程匹配。
