Proxy & Exit

代理与出口

无 Agent 可经 Relay Server 代理；检测到本机 Agent 时也可选择委托 Agent 分流。

浏览器代理

启用后由此 Chrome Profile 的 PAC 决定哪些 HTTP(S) 请求进入代理，Server 依据同一版本策略选择出口。

无 Agent 模式需要独立 browser.proxy.use 审批。通过 Server TLS 中继，不依赖会话同步配对。Agent 模式复用 Agent 原有 ACL 与出口分流。

断线保护

代理不可达或出口撤销时，不自动回退 DIRECT

网络边界与故障处理

代理接管范围

仅浏览器 HTTP(S)/适用的 WebSocket 连接。不能替代 Agent 的系统代理、进程识别或 VPN。

DNS / QUIC / WebRTC

分别验证 Chrome 的内置网络行为；WebRTC UDP 与系统 DNS 不受 PAC 完整覆盖。

断线与控制权

未授权、失去控制权或 Server/Exit 不可达时明确报错，不静默回退 DIRECT。
