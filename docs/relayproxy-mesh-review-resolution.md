## 代码盘点门禁（R-20）

逐个 Server 权责输出 **实际函数入口 → 状态存储 → 调用者 → 消息协议 → 资源 Owner → Mesh 替代/保留 → 回归测试** 的清单：

1. 设备入网/审批与身份密钥路径；
2. Server 签发的 P2P/Public Direct ticket 与 epoch；
3. 连接协调、端点注册、公网验证、NAT 打洞与 Relay 回退；
4. Server ACL / Exit ACL 的交集规则；
5. RDP ingress、文件共享授权、浏览器扩展同步与消息渠道隔离；
6. SQLite 迁移、设备撤销与跨身份授权；
7. Admin Web、Agent Web 及 Android 运行时差异。

每项需 **真实路径和函数名 + 测试名 + 风险等级 + PR 编号**。目前没有完成完整树检索和函数级审查，因此不能将 `internal/rdp/*`、`TunnelSession` 的复用范围写成已经确认的事实。

## 限制和下一步

- 未更新旧 Server/Agent 代码；三个专题设计必须过维护者、安全评审，并有跨平台签名测试向量后才冻结。
- 独立撤销集合可能导致恶意 revoke-only 管理员大范围误封，恢复与委托范围必须通过密钥管理专项测试。
- P0 必须完成 R-20 并跑旧版回归；P2 未完成撤销传播、回滚与 Owner 授权门禁之前不能切断 Server 控制面。
