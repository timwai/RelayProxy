# RelayProxy 设备中心式界面重构（Device-first）

> 状态：第一阶段 Agent React 导航与设备工作台已实现；Server Web、Android 和原生独立文件窗口按本文继续推进。

## 设计原则

**设备是主语，能力是动词。** 用户先确认操作哪一台设备，再选择该设备当前允许的操作。不在主导航里平铺“出口选择 / 远程桌面 / 文件共享 / RDP / DNS”这些互相竞争的功能入口。

- 本机：系统代理、分流、DNS、出口共享、本机文件共享、诊断属于**本设备的配置**。
- 远程设备：远程桌面、访问共享文件夹、使用其网络出口属于**该远程设备提供的能力**。
- 全局：活动、消息、实时监控、Server 连接与个人偏好属于跨设备入口，不归属任意远程设备。
- 设备主键是经 Server 认证的稳定 device_id，不以显示名称关联，更不能靠文件名、IP 或临时路径合并设备。
- 搜索、选择、最近使用、授权状态和传输中的设备上下文需贯穿全流程。

## 一级信息架构

```text
我的设备
├── 当前设备（本机）
│   ├── 运行概览 / 当前链路
│   ├── 本机代理 / 出口选择 / 分流规则 / DNS
│   ├── 出口共享
│   ├── 文件共享管理与授权
│   ├── 远程桌面控制端配置
│   └── 身份、诊断、设置
├── 远程设备 A（Server 当前批准能力的并集）
│   ├── 概览：在线状态 / 设备身份 / 授权能力
│   ├── RDP（仅有 rdp.host 授权）
│   ├── 共享文件（仅通过实时 ACL 验证的共享目录）
│   └── 网络出口（仅有 proxy.exit 授权）
└── 远程设备 B ...
全局活动
├── 消息
├── 实时连接
└── 诊断与日志
设置
```

### 交互与视觉

桌面侧边栏主入口是“我的设备 + 本机 + 已授权远程设备”，而不是功能树。点击设备进入设备工作台；工作台内显示可用能力、当前状态和操作按钮。原有复杂配置仍复用成熟功能页，避免一开始迁移所有业务逻辑。

在较窄窗口中，侧栏折叠为图标栏；后续可加设备列表抽屉。文件浏览器仍允许专注模式、分栏拖动、系统拖拽和右键操作，宜在设备页点击“浏览文件”时直接打开当前设备第一个经过验证的共享目录。

### 权限与状态

- device_id 合并来源：当前会话返回的已授权出口、RDP 目标，以及已通过本机 Agent 实时 share ACL 验证的文件设备。
- 文件设备不能因为仅有 files.host 或上次缓存就被展示；无有效共享 ACL 证明时不展现文件能力。
- Server 断连时不能把旧授权库存当作当前可执行设备列表。
- RDP 和代理操作需复用各自的 Server 端及 Agent 端校验；前端是否显示按钮不是授权机制。
- 只读目录不出现写入、移动、删除操作；断连或撤销权限要同步清空缓存与操作上下文。
- 在线状态不得从单纯的设备发现记录伪造，应使用业务 API 报告或明确显示状态未知。

## 后续阶段

### P1：深入统一设备操作

1. 将 RDP 会话、文件浏览、网络出口的状态与传输任务统一放在设备详情内，减少跳转到旧功能页。
2. 独立窗口文件浏览器：Wails / macOS 原生可调整窗口，Web 使用满屏工作区；共用设备上下文和权限校验。
3. 设备列表搜索、分组、收藏、最近连接、连接质量需基于可信数据，不能把模拟字段作真实状态。
4. 文件重命名、目录创建、移动、删除都必须先实现后端受控文件操作、路径验证和 ACL 再允许 UI 提交。
5. 跳转期间保留当前设备、共享目录及筛选，并支持浏览器历史导航。

### P2：跨端一致

- Android：底栏改为“设备 / 活动 / 我的”；选择设备后显示其 RDP、文件、出口能力；前端页面适配触控，原生 SAF 负责文件选择。
- Server Web：保留管理员“概览与全局设置”，但“设备”作为资源管理主入口；进入设备后可管理审批、授权、出口、RDP、共享审计和事件。必须严格按身份隔离。
- Windows / macOS：共用 React 设备工作台，保留窗口大小/位置和系统托盘；原生文件浏览器独立窗口可后续实现。

## 验收要求

- 当前身份下无授权设备时不显示其他身份资产；断线时远端操作不可用。
- 同一设备兼具 RDP、文件和出口能力时只出现一张设备卡。
- 文件夹列表只出现发起设备已有有效只读或读写 ACL 的目录。
- 原有代理/DNS/分流/出口/消息/监控/日志功能仍可到达，且保存/重启提示不回归。
- 被修改的配置在切换设备时仍触发“放弃修改”确认。
- Wails / 本地 Web 正常启动、适配 820px 以下窗口，已知 deep links 仍可访问。
- 设备工作台调用现有 RDP 与出口 API，失败时明确反馈，不绕过鉴权。
